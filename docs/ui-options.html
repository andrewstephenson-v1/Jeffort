Jeffort · UI options

Where the savings show up

Jeffort sets the effort level for each turn from Jev's score, never touching the model. Six ways to put its status, its toggle and the session's estimated saving above the prompt. Every strip below is drawn with the same pieces the mod can use in a terminal today: rows of text, filled boxes sized by weight, and buttons.

Example session 11 turns Baseline xhigh Output used 12.4k Saved (est.) 21.9k Cache rebuilt once 21.8k Net +$0.26
Recommendation

Option 2 by default, Option 5 when you press it

One quiet line costs a single row above the prompt, and it carries the three things you act on: the current level, whether it is on, and what it has saved. Pressing the savings expands the cost receipt, which is the only view that shows the one-time cache rebuild eating into the saving. That matters: early in a session the net can be negative, and a bar that hides it would overstate the benefit.

Honesty. Dollars on one axis, so the one-time cache rebuild is visibly taken out of the saving rather than footnoted.

About the name

Jeffort reads as Jev plus effort, and says what the mod does in one word. If you rename, the plugin name, the slash command (/auto-effort would become /jeffort), the stored settings key and the .claude-plugin manifest all change together, and the lifetime totals saved under the old key would be orphaned unless migrated.

Figures in these strips are an example session, not measured output. The saving is estimated from fixed per-level output ratios taken from the benchmark in bench/.
